# INCLUDE-50 label map attribution

`label_map_include50.json` is the official INCLUDE-50 label-to-index map copied from the AI4Bharat/INCLUDE repository file [`label_maps/label_map_include50.json`](https://github.com/AI4Bharat/INCLUDE/blob/master/label_maps/label_map_include50.json), verified against the raw official file on 26 October 2026: <https://raw.githubusercontent.com/AI4Bharat/INCLUDE/master/label_maps/label_map_include50.json>.

The application validates 50 entries, contiguous indices 0–49 and `court` at index 8 at startup. The source map is included so the frontend can validate labels without a separate download; official model code and checkpoint remain external assets.
